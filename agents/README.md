# Agent roles

Use role prompts together with `AGENTS.md`, `plan.md`, corpus policy, assigned scope,
budgets and the document schema. Prompts are reusable instructions, not an installed runner.
Start from `HANDOFF.md`, Orchestra governance and your assigned workstream status.
Register assignment/resources, write isolated outputs and append a real handoff when finished.

| Prompt | Role |
|---|---|
| [coordinator.md](coordinator.md) | Dispatch, budgets and reporting |
| [scout.md](scout.md) | Independent disease discovery |
| [verifier.md](verifier.md) | Publisher/version/access verification |
| [extractor.md](extractor.md) | Local extraction and layout fidelity |
| [curator.md](curator.md) | Canonical manifest, identity and dedup |
| [qa_reviewer.md](qa_reviewer.md) | Evidence QA and human review handoff |
| [rag_engineer.md](rag_engineer.md) | CPU baseline, variants and citation-aware Q&A |
| [evaluator.md](evaluator.md) | Reviewed gold set, course metrics and ablation |

Never mark a document human-approved on behalf of a person.
