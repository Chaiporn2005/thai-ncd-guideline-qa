Page Tag Review บันทึกอัตโนมัติในเบราว์เซอร์นี้ ไม่มีการอัปโหลด

แต่ละกลุ่มมีภาพหน้าตัวอย่าง (สุ่มกระจายตามเอกสาร) ดูว่าทั้งกลุ่มตัดหรือลบได้จริงไหม แล้วกดปุ่มของกลุ่ม หรือกด ดูทุกหน้า เพื่อเลือกรายหน้า (ตัดสินรายหน้าทีหลังจะทับการตัดสินระดับกลุ่ม) · คลิกภาพเพื่อเปิด PDF หน้านั้น

ป้ายประชากรบอกว่า หน้านั้นเขียนสำหรับใคร ไม่ใช่ว่ามีคำนั้นในหน้า: ระบบดูชื่อบท ความหนาแน่นของคำเฉพาะกลุ่ม และตัดคำที่ไม่ใช่เนื้อหา (ชื่อองค์กร, รายการอ้างอิง, ข้อควรระวังในบทผู้ใหญ่) · หน้าที่แค่เอ่ยถึงผ่าน ๆ ไม่ถูกแนะนำ (ติ๊ก "แสดงหน้าที่แค่เอ่ยถึง" เพื่อดู) · ปนกัน = เนื้อหาผู้ใหญ่ทั่วไปมีส่วนเฉพาะกลุ่มปนอยู่ (ยังค้นพบได้ในคำถามผู้ใหญ่) · ทุกหน้าที่ไม่ติดป้ายถือเป็น ทั่วไป/ผู้ใหญ่ · ความมั่นใจ สูง = ชื่อบทและหน้าตรงกัน หรือหน้าเด่นชัดมาก

หน้าที่ต้องตัดสินเรื่องข้อมูลส่วนบุคคล · เก็บไว้ = เข้า index ตามเดิม · ลบเฉพาะที่ติ๊ก = แทนค่าที่ติ๊กด้วยป้าย เช่น [เบอร์โทรบุคคล] · ไม่เข้า index = ตัดทั้งหน้า (ข้อความหายจากไฟล์) · แท็กรายชื่อบุคคล = เก็บข้อความไว้ในระบบพร้อมแท็ก PDPA แต่ไม่ให้ค้น · ไม่ต้องตัดสิน (เก็บอัตโนมัติ): ชื่อผู้จัดทำแผ่นพับ/อินโฟกราฟิก, ชื่อไม่กี่คนในเนื้อหา, เบอร์/อีเมลของหน่วยงาน

หน้าที่ถ้าเข้า index จะกลายเป็น chunk ที่ไม่มีประโยชน์หรือเป็นขยะ · ไม่เข้า index = ตัดหน้านี้ออก (ข้อความเดิมยังอยู่ในไฟล์ให้ตรวจย้อน) · เก็บไว้ = เข้า index ตามเดิม · ส่ง OCR ใหม่ (เฉพาะข้อความเสีย) = ไม่เข้า index จนกว่าจะ OCR และตรวจใหม่ · หน้าที่เก็บแต่สั้น chunker จะรวมกับหน้าข้างเคียงให้ภายหลัง
