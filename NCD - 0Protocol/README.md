# Protocol กลาง

ปรับรูปแบบการทำงานจาก `E:/งาน/งาน/Kaggle/kaggle-team/` สำหรับ Thai NCD Guideline Q&A
ใช้เป็นคู่มือเริ่มงานและส่งต่องาน ไม่ใช่คำสั่งให้เริ่ม agents หรือบริการเบื้องหลัง

อ่าน [PROTOCOL.md](PROTOCOL.md) ก่อนเริ่มรอบใหม่ และใช้ templates เมื่อเพิ่มงาน:

- [HANDOFF](templates/HANDOFF.md): ให้ session ถัดไปรับงานได้
- [STATUS](templates/STATUS.md): สถานะเฉพาะสายงานพร้อมเจ้าของไฟล์
- [RUN](templates/RUN.md): บันทึกสิ่งที่รันจริง รวมผลและข้อจำกัด

ข้อกำหนดรายวิชาอยู่ใน [plan.md](../plan.md); นโยบายเอกสารอยู่ใน
[corpus_policy.md](../docs/corpus_policy.md) หากตัวอย่างจาก Kaggle ต่างจากงานนี้ ให้ใช้ข้อกำหนด NCD
ไม่ย้าย credentials, ค่าใช้จ่าย, dataset, กฎการแข่งขัน หรือ path เครื่องอื่นจากต้นแบบมาใช้
