# Track B: silver questions

สร้าง `silver.jsonl` ครบ 44 รายการ ตามลำดับ input ตั้งแต่ q01–q44 ไม่มี id ที่ขาด แต่บางรายการมีข้อจำกัดด้านคุณภาพตามรายการด้านล่าง ทั้งหมดเป็น silver ที่ยังไม่ได้รับการตรวจรับโดยคน ไม่ใช่ gold หรือคำแนะนำทางคลินิกที่รับรองแล้ว

## จำนวนตาม stratum

| Stratum | จำนวน | Explicit | ไม่ระบุคำประชากรตรง ๆ |
| --- | ---: | ---: | ---: |
| adult_near_special | 24 | 0 | 24 |
| pregnancy | 5 | 3 | 2 |
| elderly | 5 | 3 | 2 |
| pediatric | 6 | 3 | 3 |
| mixed | 4 | 1 | 3 |
| รวม | 44 | 10 | 34 |

## จำนวนตาม asker

| Asker | จำนวน | Explicit | Situational | คำถามทั่วไป |
| --- | ---: | ---: | ---: | ---: |
| adult | 25 | 0 | 0 | 25 |
| pregnancy | 7 | 4 | 3 | 0 |
| elderly | 5 | 3 | 2 | 0 |
| pediatric | 7 | 3 | 4 | 0 |
| รวม | 44 | 10 | 9 | 25 |

`population_explicit=false` รวม 34 ข้อ แยกเป็น situational 9 ข้อ และคำถามทั่วไป 25 ข้อ จึงไม่ควรนับ false ทั้งหมดว่าเป็น situational ประชากรพิเศษ แบบ situational ใช้บริบท เช่น อุ้มท้อง ลูกอายุ 8 ขวบ หรือคุณยายอายุ 78 ปี อายุที่ใส่เป็นสถานการณ์สมมติ ไม่ใช่ข้อมูลผู้ป่วยจริงหรือเกณฑ์อายุเพิ่มเติมจากต้นทาง

Mixed เลือกตามเนื้อหาที่ถาม: q08 adult, q13 pregnancy, q18 pediatric, q22 pregnancy

## รายการที่ยังสร้างคำถามคุณภาพดีตามเป้าหมายไม่ได้

คงหนึ่งคำถามต่อ input ไว้ครบเพื่อให้ supervisor ตรวจ แต่แนะนำให้ผู้ตรวจพิจารณาเปลี่ยน input ของรายการต่อไปนี้ก่อนใช้เป็น gold:

- **q01:** มีเพียงสารบัญ ไม่มีข้อแนะนำหรือข้อเท็จจริงทางคลินิก คำถามที่เขียนอาศัยการจัดกลุ่มหัวข้ออาหารสำหรับความดันโลหิตสูง หัวใจ และอัมพาต จึงเป็นคำถามเรื่องการจัดกลุ่มหัวข้อ ไม่ใช่คำถามดูแลผู้ป่วยที่ดี
- **q26:** มีเพียงบรรณานุกรม คำถามอาศัยชื่อการศึกษาเรื่องการวัดกระดูกยาวเพื่อประมาณส่วนสูงในคนไทยวัยผู้ใหญ่ ไม่ยืนยันวิธีปฏิบัติ ความแม่นยำ หรือการใช้กับอายุ 78 ปีโดยเฉพาะ จึงไม่ควรนำไปอ้างเป็นคำแนะนำสำหรับผู้สูงอายุ
- **q32:** มีเพียงบรรณานุกรม ไม่มีคำตอบเรื่องการดูแลเด็ก คำถามจึงถามหน่วยงานที่จัดทำข้อมูลการเจริญเติบโตจากรายการบรรณานุกรม เป็นคำถามค้นหาแหล่งข้อมูล ไม่ใช่ clinical factoid
- **q36:** เป็นประวัติผู้เขียน ไม่ใช่เนื้อหาคำแนะนำ คำถามใช้เพียงข้อความเรื่องขอบเขตงานวิจัยด้านพฤติกรรมการบริโภค โดยไม่คัดชื่อหรือข้อมูลติดต่อ จึงมีคุณค่าต่อการประเมิน retrieval ทางคลินิกจำกัด

## ข้อสังเกตสำหรับผู้ตรวจ

- q11 เป็นข้อเท็จจริงด้านการทบทวนตัวชี้วัดบริการจากคำนำ ไม่ใช่ข้อแนะนำรักษาโรค
- q27 ใช้ช่วงอายุที่ระบุชัดในชื่อการศึกษา SEANUTS ในบรรณานุกรม ตอบได้เฉพาะขอบเขตอายุ ไม่รองรับข้อสรุปผลวิจัยหรือคำแนะนำอาหาร
- q05 คง asker เป็น elderly ตาม input แต่ข้อความที่ใช้เปรียบเทียบความเสี่ยงหลังไตวายเฉียบพลันไม่ได้ระบุว่าเป็นค่าประมาณเฉพาะผู้สูงอายุ
- q14 และ q44 ถูกกำหนดเป็น adult_near_special แม้เนื้อหาส่วนใหญ่เกี่ยวกับการตั้งครรภ์และเด็กตามลำดับ จึงเลือกเฉพาะข้อปฏิบัติทั่วไปเรื่องกินธาตุเหล็กพร้อมอาหารและการตรวจเครื่องชั่ง คง label ตาม TASK และไม่ใส่คำประชากรในคำถาม ควรตรวจ label ของ input ก่อนใช้วัดผลประชากร
- q20 เป็นตารางที่ข้อความหลายคอลัมน์ปะปนกัน จึงเก็บ evidence เป็น substring ต่อเนื่องตามจริง รวมข้อความแทรกระหว่างค่า LDL และ HDL ไม่ประกอบข้อความใหม่จากคนละตำแหน่ง
- q22 มีข้อความสกัดเพี้ยนบางส่วน แต่ข้อความเป้าหมายวางแผนดูแลรายบุคคลร้อยละ 100 อ่านได้ตรง จึงถามเฉพาะจุดนั้น
- q28 ถามเฉพาะเวลาเจาะเลือดสำหรับ 100 กรัม OGTT ไม่ใช้ตัวเลขของ 75 กรัมที่มีความต่างระหว่าง input แต่ละรายการ
- q35 ระบุสหรัฐอเมริกาในคำถามตามต้นทาง ไม่เปลี่ยนข้อมูลต่างประเทศให้เป็นข้อมูลประชากรไทย

## การตรวจที่ทำแล้ว

- ตรวจทุก `evidence` ด้วย Python ว่า `evidence in text` เป็นจริง และยาว 20–200 อักขระ **ก่อนเขียนแต่ละ row** รวมถึงตรวจใหม่เมื่อปรับ q05
- ตรวจครบ 44 แถว ลำดับ id ตรง input, key/stratum ตรงต้นทาง, relevant_keys มีเพียง key ของรายการนั้น, มีเฉพาะ 8 ฟิลด์ที่กำหนด และ population_explicit เป็น boolean
- ตรวจ adult_near_special ทั้ง 24 ข้อว่า asker เป็น adult และไม่มีคำประชากรพิเศษ ตรวจ stratum เฉพาะประชากรว่า asker ตรง page_population
- ตรวจความยาวคำถามด้วย Node.js v24.16.0 / ICU 78.3 `Intl.Segmenter('th', {granularity: 'word'})` โดยนับเฉพาะ `isWordLike`: ทุกข้ออยู่ระหว่าง 20–28 คำ ผ่านเกณฑ์ 10–40 คำตามวิธีตัดคำนี้ ไม่ใช้การแยกด้วยช่องว่างซึ่งไม่เหมาะกับภาษาไทย
- ตรวจข้อความคำถามและ evidence ที่เลือกว่าไม่มีชื่อบุคคล หมายเลขโทรศัพท์ หรืออีเมล และไม่มีการอ้างหน้า เอกสาร หรือบทในคำถาม
- ไม่ใช้ network, API, git หรืออ่าน `.env`; ไฟล์ที่เขียนมีเพียง `silver.jsonl` และ `SILVER_SUMMARY.md` ภายในโฟลเดอร์งานนี้ ไม่มีการแก้ corpus, manifest, registry หรือ workflow
- ไม่ตรวจเทียบ PDF ต้นฉบับ ไม่รับรองความถูกต้องทางคลินิกหรือความเป็นปัจจุบัน และยังไม่ได้รันสคริปต์ของ supervisor
