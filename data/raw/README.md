hash, ขนาด และจำนวนหน้าที่ตรวจได้จริง ไม่รวมเนื้อหา PDF

ในเครื่องมี `source.pdf` 30 ไฟล์ ส่วนอีก 16 รายการยังไม่มี PDF ที่ดาวน์โหลดได้

[rights review](../manifests/rights_review_20261005.json)
