# Decision 0003 — รวบรวมอย่างน้อย 50 เอกสาร ครอบคลุม CKD และ NCD Clinic Plus

- Date: 2026-10-05
- Decision maker: coordinator ตามคำขอผู้ใช้
- Request: “ลองหาข้อมูลให้ครบ 50 เอกสารได้ไหม หาทุกโรคกับ CKD (optional scope) และ NCD Clinic Plus”
- Outcome: accept
- Collection scope: Thai adult DM, HT, dyslipidemia, optional CKD และ NCD Clinic Plus/service
- CKD: ผู้ใช้อ้าง optional scope โดยตรง จึงอนุญาตค้น/จัด metadata ในรอบนี้;
  รักษา CKD เป็น optional ไม่เปลี่ยน core diseases และไม่อนุมัติ clinical inclusion แทนคน
- Format: คง PDF/คู่มือตามความต้องการเดิม; ไม่ใช้ JPG, mirrors, chapters หรือฉบับเก่าเติมยอด
- Target: อย่างน้อย 50 eligible candidate works หลังกันรายการ format/identity/scope ที่ไม่เหมาะออก
- Counting: candidate/source_verified counts แยกจาก accepted corpus; ยังไม่อ้างผ่านเกณฑ์วิชา
- Resources: <=3 workers, <=8 queries/worker, <=30 PDF retrieval attempts/run;
  existing session tools, no new paid API allocation
