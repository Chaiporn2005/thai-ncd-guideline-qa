## 4. สิ่งที่ต่างจากคู่มือในการทดสอบ (เงื่อนไขของการทดสอบ)
1. การ activate venv ในขั้น 3–8 ทำล่วงหน้าโดยเครื่องมือถ่ายภาพ (`-Pre`) เพราะแต่ละหน้าต่างเป็นเซสชันใหม่ จึงมีคำนำหน้า `(.venv)` ในภาพ
2. ขั้น 4 ไฟล์ zip ถูกคัดลอกจากโฟลเดอร์จำลอง `_setup_test\drive` ไม่ได้ดาวน์โหลดจาก Drive จริง
3. คำสั่งที่ใช้ถ่ายภาพต่อกันหลายคำสั่งในหน้าต่างเดียว (ขั้น 1, 2, 4, 5) ตามที่ระบุในคำบรรยายภาพ
4. ใช้ `powershell -NoProfile -ExecutionPolicy Bypass` ในเครื่องมือถ่ายภาพ ไม่ได้ทดสอบนโยบาย PowerShell แบบเข้มงวดของเครื่องเพื่อน
5. เครื่องทดสอบ: Windows 11 (NT 10.0.26200), Windows PowerShell 5.1, Windows Terminal, RAM ~31.6 GB, จอ 1280×800 (logical) ขยายหน้าจอ, uv 0.11.25, Git 2.53.0 และมีแคชของ uv/โมเดลอยู่ก่อน
6. ภาพขั้น 8ก ถ่ายจาก browser pane (viewport จำลอง 1100×900 โทนสว่าง) ไม่ใช่เบราว์เซอร์ของผู้ใช้

## 6. ความผิดพลาดที่เกิดขึ้นจริง (ยอมรับ)
**ของ Claude (ผม):**
1. **ภาพรั่วหน้าต่างอื่น (ร้ายแรงที่สุด):** เครื่องมือถ่ายภาพรุ่นแรกคัดลอกพิกเซลจากจอโดยไม่ตรวจว่าหน้าต่างเทอร์มินัลอยู่บนสุด ผลคือภาพขั้น 4, 5, 6 ของรอบที่สอง (ที่ผมเปิดดู) เป็น **หน้าต่างแอป Claude ของผู้ใช้** (เห็นรายชื่อแชตส่วนตัวและชื่อบัญชีที่แถบซ้าย) ส่วนขั้น 7, 8 ขนาดไฟล์เท่ากันทุกไบต์กับสามภาพนั้น (189,306 ไบต์ ผมไม่ได้เปิดดู แต่ลบด้วย) ผมลบไฟล์ทั้ง 5 ภาพทันที ไม่ได้ commit หรือส่งไปที่ใด (ภาพถูกอ่านโดยผมเท่านั้นในเซสชันนี้) แก้เครื่องมือให้บังคับหน้าต่างอยู่บนสุดและ **ปฏิเสธบันทึกภาพถ้ากลางภาพและมุมทั้งสี่ไม่ใช่หน้าต่างของมันเอง** (ทดสอบแล้ว: ภาพสุดท้ายทุกภาพเป็นเทอร์มินัล)
2. เครื่องมือถ่ายภาพมีบั๊กต่อเนื่อง ผมแก้ทีละอัน: ภาพถูกตัดขอบเพราะจอขยาย 150% (ต้อง DPI-aware); ผลลัพธ์จาก native command (uv, git) ถูกกลืนเพราะใช้ `Invoke-Expression ... 2>&1` (ต้องใช้ `*>&1` ใน script block) ทำให้ภาพขั้น 3 ในรอบแรกว่างเปล่า; นิพจน์พิกัดผิดทำให้สคริปต์ล้มก่อนถ่าย (ไม่มีภาพเลยในรอบหนึ่ง) และทิ้งหน้าต่างเทอร์มินัลค้าง 9 หน้าต่าง (ปิดแล้วด้วยการจับเฉพาะชื่อที่ขึ้นต้นตามที่ผมตั้ง)
3. ตัวเฝ้าของผมแจ้ง "รันเสร็จ" ผิดครั้งหนึ่ง เพราะอ่านไฟล์ log ของรอบเก่าก่อนที่สคริปต์จะล้างมัน ผมสังเกตจากเวลาที่เท่ากันทุกขั้นพอดี ตรวจใหม่ ก่อนใช้ภาพใดๆ
4. ร่างคู่มือรุ่นแรกเขียนผลที่คาดของขั้น 7 ผิด (บอกว่า [5][6] และ [8] เป็นกลุ่มเดียวโดยไม่รวม [4] ที่เป็น `abstained_model`) และขั้น 5 เขียนให้ `Copy-Item .env.example .env` ซึ่งทับ `.env` เดิมที่ใส่คีย์ไว้ได้ (astra จับข้อหลังได้ในข้อ 16) แก้แล้ว
5. ขั้น 2 ในร่างแรกไม่ได้ทดสอบกรณี `Activate.ps1` ถูกบล็อก ยังไม่ได้ทดสอบจนถึงตอนนี้ (ระบุไว้ในคู่มือ)
6. ก่อนหน้านี้ในเซสชันเดียวกัน (ไม่เกี่ยวกับคู่มือ) ผมใช้ `taskkill /F /IM python.exe` ปิดทุกโปรเซส Python บนเครื่องตอนรีสตาร์ตงานประเมิน ซึ่งอาจกระทบโปรเซสอื่นของผู้ใช้ ผมไม่ได้ตรวจว่ากระทบอะไร ควรใช้การปิดเฉพาะ PID ของตัวเอง (รอบถัดมาที่ปิดเซิร์ฟเวอร์เดโม ผมกรองตามบรรทัดคำสั่งแล้ว)
**ของ astra (จากรายงานของมันเองและที่ผมตรวจ):**
1. ครั้งที่ 1: ทำสคริปต์ช่วย `run_step.ps1` ที่ไม่ได้ขอ และมันบันทึก `OK` ทั้งที่ล้มเหลว (การ cd ล้มแต่ log OK) มันรายงานแก้ไขเอง และเก็บข้อมูลดิบไว้ ผมตรวจแล้วว่ารายงานสรุป (FAILED 1 / BLOCKED 7, 0 ภาพ) ตรงกับสภาพจริง
2. ตั้งค่า TEMP/TMP เฉพาะโปรเซสของมันให้ชี้เข้าโฟลเดอร์งาน (เปิดเผยในรายงาน ไม่ใช่การตั้งค่าเครื่อง); พิมพ์เครื่องหมายคำพูดซ้อนผิดในคำสั่งขั้น 8 หนึ่งครั้ง; ขั้น 2 รันในโฟลเดอร์ผิดหนึ่งครั้ง (ไม่สร้างอะไรเสียหาย ตรวจแล้วว่าไม่มี `.venv` ที่ราก)
3. ครั้งที่ 2: ส่งข้อความความคืบหน้าทั้งที่ผมขอเฉพาะข้อความสุดท้าย และค้นไฟล์ความจำของ Codex เอง (`~/.codex/memories`) ซึ่งอยู่นอกขอบเขตงาน กติกาของผมไม่ได้ห้ามข้อนี้ไว้ชัด (ช่องโหว่ของกติกา) มันบอกเองใน "My own errors and gaps" และบอกว่าไม่ได้ใช้ข้อมูลนั้นตัดสิน
4. มันยืนยันตัวเองไม่ได้ว่ารันเป็นโมเดล astra จริง (ผมสั่งผ่าน `-m gpt-6-astra` แต่ไม่ได้ตรวจหลักฐานฝั่งผู้ให้บริการ)

## 7. ยังไม่ได้ทดสอบ
- เครื่องที่ไม่มีแคช uv/โมเดลเลย (ดาวน์โหลดโมเดล bge-m3 จากศูนย์ และเวลาจริงบนเน็ตจริง)
- คีย์ API ที่ถูกต้อง (คำถามใหม่ที่เรียก Typhoon จริงจากเครื่องเพื่อน), คีย์ผิด
- เครือข่ายถูกตัดจริง (ทดสอบเพียงการจำลองด้วย proxy ปลอม + `HF_HUB_OFFLINE=1`)
- Windows 10, macOS/Linux, นโยบาย PowerShell ที่เข้มกว่าปกติ, `Activate.ps1` ถูกบล็อก
- การดาวน์โหลดจาก Drive จริงและสิทธิ์โฟลเดอร์ (ลิงก์ยังไม่มี), การรัน bundle ซ้ำ/zip เสียหาย
- โหมดเสริม `--graph`, `--agent react`, `--variant C` ในสภาพไม่มีคีย์/ไม่มีแคช
- การเปิดเว็บบนเบราว์เซอร์อื่นนอกจาก browser pane

## 8. ถ่ายภาพใหม่ได้อย่างไร
`scripts/capture_terminal.ps1` (Windows PowerShell 5.1 + Windows Terminal): เปิดหน้าต่าง Windows Terminal ใหม่หนึ่งหน้าต่างรันคำสั่งที่ให้ รอจนจบ บังคับให้อยู่บนสุดและยืนยันว่าเป็นหน้าต่างบนสุดที่กลางและมุมทั้งสี่ (ไม่ใช่ → ไม่บันทึกภาพ) คัดลอกพิกเซลเฉพาะหน้าต่างนั้น ตัดพื้นที่ว่างท้ายภาพ และบันทึกข้อความผลลัพธ์เป็น `.txt` ข้างภาพ ห้ามใส่ความลับในพารามิเตอร์ `-Command`/`-Pre` เพราะคำสั่งแสดงในภาพ ตัวอย่างอยู่ใน `docs/setup_test/scripts/run_final.sh`
