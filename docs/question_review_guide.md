# คู่มือตรวจคำถาม dev/test (สำหรับเพื่อนร่วมทีม)

คำถามชุดนี้ Codex (gpt-6-astra, reasoning medium) ร่างจากหน้าเอกสารจริงเมื่อ 2026-10-10 ทุกข้อยังเป็น **silver** (AI ร่าง) จนกว่าคนจะตรวจ
เมื่อคนตรวจแล้วจึงเป็น **gold** ซึ่งเป็นชุดที่ใช้ตัดสินผล retrieval ของทีม จึงต้องตรวจจริง ไม่ใช่กดผ่านทั้งหมด

| ส่วน | ไฟล์ | ผู้ตรวจ |
|---|---|---|
| 1 | เก็บในเครื่องเจ้าของ Track B (มีข้อความหน้าเต็ม และรวมคำถามจากเอกสาร Siriraj) | เจ้าของ Track B |
| 2 | `data/questions/review/review_part2.html` | [FILL IN: ชื่อเพื่อน] |
| 3 | `data/questions/review/review_part3.html` | [FILL IN: ชื่อเพื่อน] |
| 4 | `data/questions/review/review_part4.html` | [FILL IN: ชื่อเพื่อน] |

ข้อสอบ test ควรให้คนที่ **ไม่ใช่** เจ้าของ Track B ตรวจเป็นหลัก (ส่วน 3 มี test มากที่สุด)

## ขั้นตอน

1. ดึงโค้ด: `git checkout main && git pull`
2. เปิดไฟล์ HTML ของส่วนตัวเองด้วย Chrome/Edge (ดับเบิลคลิกจาก File Explorer หรือลากเข้าเบราว์เซอร์) ไม่ต้องติดตั้งอะไร
3. กรอก **ชื่อผู้ตรวจ** มุมบนของหน้า (บังคับ ใช้บันทึกใน gold)
4. แต่ละข้อมีคำถาม คำตอบร่าง และ quote ที่ Codex อ้างจากเอกสาร: กด "เปิดต้นฉบับ" ไปที่หน้า PDF ที่ระบุ (นับหน้าแรกของไฟล์ PDF เป็นหน้า 1) แล้วเช็ก
   - ตอบได้จากหน้านั้นจริง และ quote ตรงกับคำตอบ
   - คำถามเข้าใจได้โดยไม่ต้องเห็นหน้า ไม่มีคำว่า "ตามตารางนี้" และไม่ได้ลอกถ้อยคำจากหน้ามาตรง ๆ
   - ข้อที่เป็น *unanswerable*: ใน corpus ต้องไม่มีคำตอบจริง ๆ (ถ้าไปเจอคำตอบ ให้ปฏิเสธและเขียนหมายเหตุว่าเจอที่ไหน)
5. เลือกหนึ่งอย่าง: **ถูกต้อง ใช้ได้** / **แก้ไขแล้วใช้** (แก้คำถามหรือคำตอบในช่องที่ขึ้นมา และ *ต้องเขียนหมายเหตุ*) / **ปฏิเสธ** (*ต้องเขียนหมายเหตุ*)
   ผลถูกเก็บในเบราว์เซอร์อัตโนมัติ ปิดแล้วเปิดใหม่ในเครื่องเดิมก็ยังอยู่ ตรวจต่อเป็นรอบๆ ได้
6. ตรวจครบแล้วกดปุ่ม **ส่งออกผล (JSON)** ที่แถบบน จะได้ไฟล์ `question_review_<part>_<ชื่อ>.json`
7. ส่งไฟล์นั้นให้เจ้าของ Track B (ส่งแชต) หรือวางไว้ที่ `data/questions/reviews/` แล้ว `git add`, `git commit`, `git push origin HEAD:review/<ชื่อ>` (ไม่ต้อง merge เอง)

ถ้าไม่แน่ใจข้อไหน ให้เลือก "ปฏิเสธ" พร้อมหมายเหตุ ดีกว่ากดผ่าน: ข้อที่ไม่ผ่านเอาออกได้ แต่ gold ที่ผิดจะทำให้ตัวเลขผลทุกตัวผิด

## เจ้าของ Track B: รวมผล

```powershell
python -X utf8 scripts/apply_question_review.py --questions data/agent_runs/20261010-silver-questions/questions_silver.jsonl `
    --reviews data/questions/reviews/*.json --out data/agent_runs/20261010-silver-questions/questions_reviewed.jsonl
```

สคริปต์หยุดถ้ามีข้อที่สองคนตัดสินไม่ตรงกัน, ข้อแก้/ปฏิเสธไม่มีหมายเหตุ หรือไม่มีชื่อผู้ตรวจ แล้วตรวจไฟล์กับ `question.schema.json` ให้
ข้อ split `test` ที่ยังเป็น silver จะไม่ผ่าน schema (ตั้งใจ: test ต้อง gold เท่านั้น)
