# โครงสไลด์ Track C (ร่าง AI; เจ้าของแก้และเป็นผู้นำเสนอ) ทุกตัวเลขอ้างจาก `runs/frozen_gen_v1/` และ `docs/`

เวลาแนะนำ 8–10 นาที ใช้ภาพตารางแทนข้อความยาว ทุกสไลด์ที่มีผลวัดต้องมีบรรทัดข้อจำกัด

## 1. ปัญหาและระบบ (1 นาที)
- ถามตอบแนวทางเวชปฏิบัติ NCD ภาษาไทย ต้อง "ตอบจากหลักฐานและอ้างอิงได้ หรือไม่ตอบ"
- แผนภาพ: คำถาม → ตัวกรองอินพุต → ค้นคืน (hybrid) → prompt → LLM → ตรวจทุก claim → ตัวกรองเอาต์พุต → คำตอบ+แหล่งอ้างอิง
- ระบบที่เทียบกัน: A dense, B hybrid, C hybrid+rerank, D BM25, pipeline LangGraph, agent ReAct

## 2. วิธีวัด (1 นาที)
- test 52 ข้อตอบได้ + 4 ข้อไม่มีคำตอบ รันครั้งเดียวหลัง freeze (`frozen_v1`, `frozen_react_v1`)
- metric: correctness (judge อ้างเฉลย), faithfulness แบบ RAGAS ที่เขียนเอง, BERTScore, citation, abstention, hit@5, token
- judge gpt-5.6-luna (หลัก) + Gemini (รอง, ครอบคลุม ~75%) ไม่มีคนตรวจ → ผลเป็นทิศทาง

## 3. ผลหลัก (2 นาที)
ตาราง (test): C 0.904 > B 0.885 > ReAct 0.827 > D 0.808 > A 0.798 (correctness)
- ข้อสรุป: hybrid ดีกว่า dense; rerank ช่วยต่อ; **ReAct ไม่ชนะ pipeline คงที่** ที่ต้นทุน ~5.5 เท่า
- BERTScore เท่ากันทั้งหมด (~0.82): ไม่ใช่บั๊ก แต่เป็นสมบัติของเมตริก (ไม่ไวต่อถูก/ผิด)

## 4. ค้นเก่ง แล้วทำไมยังพลาด (1.5 นาที) — error analysis
- ไม่ผ่าน 9/52: ค้นพลาด 3, ตอบไม่ครบ 2, validator ตัดคำตอบที่ถูก 2, อ้างชิ้นผิด 1, claim ขัดกัน 1
- ตัวอย่าง metformin ระยะ 3: claim สำคัญถูกตัดเพราะเลข 3 จากคำถาม → โปรไฟล์ N8
- ทดลองชุดแก้ v2 (prompt + validator): **ไม่ผ่านกติกาที่ประกาศก่อน** จึงไม่ใช้ (บอกตรงๆ ว่าไม่ได้ผล)

## 5. ความปลอดภัยตาม OWASP LLM Top 10 (1.5 นาที)
- 76 เคส (silver) ครอบ LLM01, 02, 05, 06, 07, 08, 09, 10; guard 3 ตำแหน่ง input/tool/output
- ผลโจมตีถึงผู้ใช้: 0.58 (ไม่ป้องกัน) → 0.09 → **0/45** (ReAct 1/51 = ผู้ใช้สั่งเอง)
- ที่กันไม่ได้โดยโครงสร้าง: chunk ปลอมที่เขียนเหมือนแนวทาง, ชื่อไม่มีคำนำหน้า

## 6. สิ่งที่พลาดและแก้ระหว่างทาง (1 นาที) — จาก AI_AUDIT
- baseline "ไม่มีป้องกัน" ไม่ได้ว่างเปล่า (ASR 0 ผิด) → แยกชั้น N0–N7
- ชุดเคส OWASP รุ่นแรกออกแบบผิด (ข้อความปลอมไม่ตรงหัวข้อ, ตัดสินด้วยวลีนับประโยคปฏิเสธ) → v2
- judge ไม่นิ่ง ±0.03 และ faithfulness เดิมต่ำเกินจริง → รายงานตัวคู่

## 7. ข้อจำกัดและงานต่อ (0.5 นาที)
- n เล็ก, silver, LLM ตัวเดียว, ตาราง/ตอบไม่ครบยังแก้ไม่ได้, ไม่ใช่คำแนะนำทางการแพทย์
- งานต่อ: chunking ตาราง, ตัวตรวจประชากรไม่ตรง, judge เพิ่ม, คนตรวจเคส

## เตรียมตอบคำถามที่น่าจะถูกถาม
- ทำไม ReAct แย่กว่า? → query drift, ไม่มีเกณฑ์หยุด, บริบทเจือจาง (dev: ปรับ seed search แล้ว hit@5 เท่า B แต่คำตอบยังไม่ดีกว่า)
- เชื่อ judge ได้แค่ไหน? → สอง judge ตรงกัน 0.87–0.92 แต่ไม่มีคนตรวจ และแปรปรวน ±0.03
- guard ปลอดภัยจริงไหม? → วัดกับเคสที่ AI เขียน; 0/45 ไม่ใช่การรับรอง (ขอบบน CI ~8%)
- ทำไมไม่รัน test ซ้ำ? → กติกาวิชา/ป้องกัน overfit; ชุดแก้ v2 ตัดสินบน dev เท่านั้น
