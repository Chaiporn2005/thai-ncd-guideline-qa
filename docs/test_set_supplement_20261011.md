## 3. สิ่งที่พบนอกเหนือจากที่ขอ (บันทึกเพื่อ AI_AUDIT)

1. **คำถาม 3 ข้อของชุดเดิมเสียเป็น `????`** (q067, q097, q112) ภาษาไทยหายตอน Codex เขียนไฟล์ผ่าน shell บน Windows เพื่อนที่ตรวจส่วน 4 จับ q067 และ q097 ได้ q112 ยังอยู่ในส่วน 2/3 ที่ยังไม่ได้รับผล ต้องปฏิเสธหรือเขียนใหม่ รอบนี้สั่งทุกโมเดลให้เขียนไฟล์ด้วยเครื่องมือเขียนไฟล์ ไม่ใช้ shell และผ่านการตรวจ
2. **ข้อ unanswerable ของชุดเดิม 10 ข้อมี evidence ติดมา แต่ `question.schema.json` กำหนดให้ว่าง** `apply_question_review.py` ที่ตรวจ schema ตอนรวมผลจึงจะไม่ผ่าน แก้แล้ว: สคริปต์เก็บหน้าที่ใกล้ที่สุดไว้ในไฟล์ข้าง `*_unanswerable_context.jsonl` แล้วล้าง evidence ตาม schema
3. **12 ข้อของชุดเดิมมี quote ซ้ำตรงตัวบนหน้าอื่น** (3 ข้อใน test: q001, q002, q037) กฎจับคู่ chunk ↔ gold ต้องรองรับ ไม่งั้น retriever ที่ดึงหน้าซ้ำถูกนับว่าพลาด
4. **การตรวจ unanswerable ต้องค้นทั้ง corpus**: โมเดลที่ไม่มี shell (Gemini) ทำไม่ได้ และคำถามที่ดูไม่มีคำตอบในเล่มเดียวอาจมีในเล่มอื่น (q177, q174)
5. **ผู้รีวิวชุด 1 ตอบ "ถูกต้อง ใช้ได้" ทั้ง 36 ข้อ** ไม่มีข้อแก้หรือปฏิเสธ ส่วนผู้รีวิวชุด 4 ปฏิเสธ 2 แก้ 2 จาก 35 ข้อ ควรสุ่มตรวจชุด 1 อีกรอบโดยเฉพาะข้อ test 9 ข้อ (เป็นข้อสังเกตจากผลที่ได้รับ ไม่ได้ประเมินว่าถูกหรือผิด)
