## 4. อ่านผลอย่างไร (และไม่ควรอ่านอย่างไร)

**สิ่งที่ผลบอก**
1. **ผลต่อความปลอดภัย (ชัด):** ไม่ใช้ป้าย → 1 ใน 18 ช่องอันดับต้นของคำถามผู้ใหญ่เป็นหน้าเฉพาะกลุ่ม (ตัวอย่างข้างบน: ค่าเป้าหมาย/วิธีแก้ของเด็กโผล่ในคำถามผู้ใหญ่); ใช้ป้ายแล้วเหลือ 0 ทุกกลยุทธ์
2. **ไม่เสียความแม่นของคำถามผู้ใหญ่ในชุดนี้:** Recall@5 เท่าเดิม 0.64
3. **ช่วยคำถามเฉพาะกลุ่มพอสมควร:** กรองเด็ดขาดดีที่สุด (Recall@5 0.79 → 0.89, MRR 0.51 → 0.67) ถ่วงน้ำหนักแรงได้ประมาณครึ่งหนึ่ง ถ่วงน้ำหนักอ่อนแทบไม่เปลี่ยน → **ผลไวต่อค่าน้ำหนัก**
4. **ตัวตรวจกลุ่มจากข้อความคำถามเกือบไม่เป็นปัญหา:** ผลแบบตรวจเองกับแบบรู้กลุ่มจริงเกือบเท่ากัน (43/44)

**ข้อจำกัด: ทำให้ผลนี้เอนเอียงเข้าข้างการติดป้าย (ต้องรู้ก่อนตัดสินใจ)**
- **ช่วงเชื่อมั่นแตะ 0 ทุกกลยุทธ์** (n เล็ก): ยังพูดไม่ได้ว่า "ดีขึ้นอย่างมีนัยสำคัญ" มีแต่ "แนวโน้มไปทางดีขึ้นและไม่เสียหาย"
- **การออกแบบชุดคำถามทำให้การกรองไม่มีทางทำร้ายตัวเอง:** คำถามเฉพาะกลุ่มสร้างจากหน้าที่ติดป้ายแล้ว จึงอยู่ในกลุ่มที่ "ผ่านตัวกรอง" เสมอ และคำถามผู้ใหญ่สร้างจากหน้าทั่วไป จึงไม่ถูกซ่อน
  **ความเสี่ยงจริงของการกรองเด็ดขาด** คือหน้าที่ติดป้ายผิดแล้วถูกซ่อนจากคำถามผู้ใหญ่ ชุดนี้วัดไม่ได้ (ความแม่นยำป้ายที่วัดได้: เด็ก 1.00, ตั้งครรภ์ 0.80 ใน DM CPG เอกสารเดียว) ถ้าติดผิดสูงสุดประมาณ 0.7% ของหน้าทั้งหมดจะถูกซ่อน
  และกรณีที่ผู้ใช้ถามเรื่องเด็กแต่คำตอบอยู่ในหน้าทั่วไป (เช่น หมายเหตุสำหรับเด็กในบทผู้ใหญ่) การกรองเด็ดขาดจะตัดหน้านั้นทิ้ง ซึ่งชุดนี้ไม่ได้ทดสอบ
- คำถามเป็น silver ที่ Codex เขียน ยังไม่ผ่านคน: 4–5 ข้อมาจากหน้าที่ไม่เหมาะ (สารบัญ/บรรณานุกรม) และ 2 ข้อ (q14, q44) เนื้อหาหน้าเอนไปทางกลุ่มเฉพาะ
- BM25 ระดับหน้าเท่านั้น: ระบบจริงใช้ chunk + dense + RRF + rerank ซึ่งอาจลดหรือเพิ่มปัญหาดึงผิดกลุ่ม (dense อาจจับ "เด็ก" vs "ผู้ใหญ่" ได้ดีกว่า)
- ขนาดหน้าเฉพาะกลุ่มที่ค้นได้ใน v8 เล็ก (127 หน้า) ผลรวมของระบบจึงเปลี่ยนได้ไม่มาก
