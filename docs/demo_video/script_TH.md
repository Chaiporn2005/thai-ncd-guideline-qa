# สคริปต์วิดีโอเดโม ฮูกไกด์ (Thai NCD Guideline Q&A)

รูปแบบ: ไม่มีเสียง + คำบรรยายไทยบนจอ · 16:9 1920×1080 · ซูมเข้า/ออกตามฟีเจอร์ · เคอร์เซอร์เคลื่อนต่อเนื่อง

## ข้อควรระวังในการพูดถึงวิดีโอนี้
- คำตอบทั้งหมดมาจากระบบจริง ไม่ได้ตัดต่อเนื้อหา แต่ **ไม่ได้พิสูจน์ว่าคำตอบถูกต้องทางการแพทย์** (ยังไม่มีผู้เชี่ยวชาญทางคลินิกตรวจ)
- ตอน 17–18 ผลของวิธี A กับ B ถูกรันไว้ก่อนแล้ว หน้าเว็บจึงแสดง "จากแคช" คำตอบเป็นของจริงของแต่ละวิธี ไม่ได้เรียก API ในวิดีโอ
- ตอน 11–15 ใช้คำถามจากชุดทดสอบระบบ (ไม่ใช่การประเมินใหม่) และตอบจากแคชหรือถูกปฏิเสธก่อนถึงโมเดล
- ตัวเลข 0/45 และผลประเมินอื่นไม่ได้อยู่ในวิดีโอนี้ ดูสไลด์
